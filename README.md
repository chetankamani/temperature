# temperature

Ahmedabad daily temperature data for simulation use cases.

## Data source

- OpenCity dataset resource: https://data.opencity.in/dataset/daily-temperature-70-years-data-for-major-indian-cities/resource/db3f6c55-bc4e-4e12-be01-49448686596b
- Repository file: `/home/runner/work/temperature/temperature/data/ahmedabad_daily_temperature_1951_2024.csv`

## Notes

- The CSV is stored as published in the source-derived dataset and contains daily records starting from `01-01-1951`.
- Header columns in the file are:
  `Date,Rain,Temp Max,Temp Min,Location,Rain,Temp Max,Temp Min,Location`
